# Erudite

## Description
This is a professional-looking website that includes a navigation bar, a hero section, and an "Upcoming Events" section. The website is designed with a sleek, modern, and 3D-styled UI.

## Features
- **Responsive Navigation Bar**: A fixed, slim navbar with smooth scrolling and active link highlighting.
- **Hero Section**: A visually appealing introduction to the website.
- **Upcoming Events Section**: Displays upcoming events in a neatly styled, centered event list.
- **Hover Effects**: Event cards and navbar links have smooth hover animations.
- **Animations**: Sections fade in as the user scrolls.
- **Fully Responsive**: Works well on all screen sizes.

## Technologies Used
- **HTML5**: Structure of the website.
- **CSS3**: Styling and animations.
- **JavaScript**: Interactive features like navbar highlighting and animations.

## Installation
1. Clone the repository:
   ```sh
   https://github.com/rajkumar8757/Erudite.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Erudite
   ```
3. Open `index.html` in a web browser.

## File Structure
```
project-folder/
│── index.html         # Main HTML file
│── styles.css         # CSS for styling
│── script.js          # JavaScript for interactivity
└── images/            # Folder for images (if needed)
```

## Usage
1. Open the website in a browser.
2. Navigate through different sections using the navbar.
3. Check upcoming events in the centered event section.
4. Experience smooth animations and hover effects.
